# What Hit Me? とは

What Hit Me? はプレイヤーが受けたダメージを記録し、死んだ理由をわかりやすい言葉で説明する mod です。

- **とどめの一撃**と**死亡メッセージ**
- **攻撃してきた相手**、その**武器**、追加している **mod**
- **防具**や**衝撃吸収**でどれだけ防げたか
- **防具無視**だったのか、**炎**・**魔法**・**爆発**・**飛び道具**だったのか
- **直前 30 秒間**のすべての被ダメージ（同じダメージの連続はまとめて `x12 hits`）
- 次に生き残るための**ヒント**

ブロックやアイテムは追加せず、ワールドにデータも残しません。クライアントだけ、サーバーだけ、両方、どの入れ方でも動きます。

## 邪魔をしない設計

- **記録するのはプレイヤーだけ。** ダメージと死亡の処理は、プレイヤー以外のエンティティなら最初の 1 行で終わります。偽プレイヤー（FakePlayer）も無視します。
- **サーバーの tick 処理はありません。** 時間の範囲、まとめ表示、反射ダメージ、クールダウンはすべてタイムスタンプの比較です。ダメージの結果を待つ必要がある確認だけ、サーバーのタスクキューに 1 回登録します。
- **通信は必要なときだけ。** 死亡時、トーテム / 大ダメージのとき、プレイヤーがコマンドを使ったときだけで、ダメージのたびには送りません。
- **カタログのキャッシュ。** ダメージの種類・mob・効果は 1 回だけ調べ、mod リストのハッシュと一緒に保存します。次回の起動で mod が同じならキャッシュから読み込みます。
- **すべての処理を保護。** イベント処理、パケット処理、スキャン、画面はそれぞれ自分でエラーを受け止め、「不明」として扱います。他の mod の壊れたデータがクラッシュにつながりません。
- **メモリも少しだけ。** 履歴はプレイヤーごとの固定サイズのリングバッファで、エンティティへの参照は持ちません。ログアウトすると破棄されます。
- **Forge / NeoForge：** 標準のイベントだけを使い、Mixin もコアモッドも使いません。**Fabric：** Fabric API のイベントと、イベントがない箇所だけの小さな Mixin を使います。

::: info 絵文字を使わない理由
古い Minecraft のフォントは絵文字を表示できません。そのため、どのバージョンでもゲームのフォントにある記号（☠ ⚠ ❤ ⚡ Σ）と文字のラベルを使っています。
:::
