# クライアント・サーバーの組み合わせ

What Hit Me? はどの組み合わせでも動きます。シングルプレイは常に「クライアントとサーバーの両方」に入っている扱いです（内蔵サーバーでも mod が動くため）。

## どのモードになる？

| 入れた場所 | プレイヤーに見えるもの |
|---|---|
| **クライアントとサーバー** | サーバーからの正確なデータ：防具で軽減する前のダメージ、軽減率、衝撃吸収、武器とエンチャント、飼い主、盾や無敵時間のフラグ、防具、周囲の状況。プレイヤー自身の言語での表示、クリップボードへのコピー、死亡画面のパネル。サーバーの `whathitme-common.cfg` と pack フォルダーが全員に適用されます。 |
| **クライアントだけ**（mod のないサーバー、バニラサーバー） | クライアントの推定：自分の体力を見て、減ったときだけ原因を推測します（落下、溶岩、炎、溺れ、窒息、奈落、近くの mob、飛び道具、爆発、毒、ウィザー、空腹）。記録には `[Client Est.]` が付きます。`/whm inspect` は使えません。進行度ルールは適用されません。 |
| **サーバーだけ**（mod なしのプレイヤー。素の Forge クライアントでも可） | サーバーが英語でチャットを送ります：リスポーン後の要約、トーテム / 大ダメージの通知、すべての `/whm` コマンド。`[Copy ID]` はクリップボードではなくチャット欄に ID を入れます。`togglechat` と `ignore` はプレイヤーごとにサーバーへ保存されます。 |

mod 入りのサーバーでは、各プレイヤーにそのクライアントで使える一番よいモードが選ばれます。mod を入れている人はすべての機能、入れていない人は英語のチャットです。

## サーバーが決めること

サーバーに mod があると、ログイン時・`/whm reload` の後・設定の変更後に、サーバーの `whathitme-common.cfg`（表示スイッチ、非表示 ID、名前、ヒント、`summarySeconds`）と pack の定義を mod 入りの全クライアントへ送ります。接続中は、これがクライアント自身の common ファイルの**代わりに**使われます。

- 表示項目は**両方**のファイルでオンのときだけ表示されます。サーバーは全員分をオフにでき、各プレイヤーはさらに自分の分をオフにできます。
- サーバーでオフにした機能（common 設定や `lockedFeatures`）は、サーバーが作るパケットからも取り除かれます。改造したクライアントでも表示できません。
- プレイヤーはサーバーの設定に加えて自分用の名前やヒントを追加できます（[進行度ルール](/ja/modpack/rules)が強制している場合を除く）。

## バージョンの混在

- 1.0 / 1.1 / 1.2 のクライアントは 1.3 のサーバーでも動き、その逆も動きます。古い側が知らない機能は使われないだけです。
- 1.3.0 の通信プロトコルは 3 です。pack のテンプレート、カスタム死亡メッセージ、ルールの結果はプロトコル 3 で接続したクライアントにだけ送られます。古いクライアントには隠すべき項目を取り除いた記録が送られます。

## mod なしのプレイヤーと 1.3.0 の機能 <Badge type="tip" text="1.3.0+" />

| 機能 | mod ありのプレイヤー | mod なしのプレイヤー |
|---|---|---|
| [テンプレート](/ja/modpack/templates) | pack のテンプレート、個人用テンプレート | サーバーの英語チャットに pack のテンプレート |
| [カスタム死亡メッセージ](/ja/modpack/death-messages) | 置き換わる | Fabric サーバー：置き換わる。Forge / NeoForge サーバー：バニラのまま |
| [進行度ルール](/ja/modpack/rules) | 適用（サーバーが判定） | サーバーが送るチャットには適用。Forge / NeoForge ではバニラの死亡メッセージは変わらない |
| [requireClientMod](/ja/modpack/require-client-mod) | 普通に参加できる | わかりやすいメッセージ付きで切断される |

::: warning Forge / NeoForge と死亡メッセージの非表示
Forge と NeoForge には、バニラの死亡メッセージを変更するイベントがありません。ルールで死亡メッセージを隠しても（または `deathMessages` を使っても）、mod なしのプレイヤーにはバニラの文章が見えます。問題になる場合は [`requireClientMod=true`](/ja/modpack/require-client-mod) にしてください。この状態のとき、サーバーは起動時と `/whm reload` 時に警告をログに出します。
:::
