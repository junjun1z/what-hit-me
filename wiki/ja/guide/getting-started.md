# インストール

## 1. ファイルを選ぶ

自分の **Minecraft のバージョン**と**ローダー**に合ったファイルをダウンロードします。ファイル名に両方が入っています（例：`whathitme-forge-1.20.1-1.3.0.jar`、`whathitme-fabric-1.21.1-1.3.0.jar`）。

| ローダー | ほかに必要なもの |
|---|---|
| Forge | なし |
| NeoForge | なし |
| Fabric | [Fabric API](https://modrinth.com/mod/fabric-api)（1.21 / 1.21.1 では 0.116 以降）。[Mod Menu](https://modrinth.com/mod/modmenu) は任意です。 |

## 2. `mods` フォルダーに入れる

1. ゲームを終了します。
2. `.jar` をインスタンス（またはサーバー）の `mods` フォルダーにコピーします。
3. ゲームを起動します。初回起動時に `config/whathitme/` が作られ、設定ファイルと [pack フォルダー](/ja/modpack/pack-folder)ができます。

これで完了です。参加時にチャットへ何かが出ることはありません。初めてダメージを受けて死んだときに mod の表示が出ます。

::: tip クライアント？サーバー？両方？
クライアントだけ、サーバーだけ、両方のどれでも入れられます。両方に入れると最も正確なデータが得られます。詳しくは[クライアント・サーバーの組み合わせ](/ja/guide/multiplayer)へ。
:::

## mod が作るファイル

```
config/whathitme/
  whathitme-common.cfg            pack とサーバーの設定
  whathitme-client.cfg            個人設定とパネルの配置（クライアントのみ）
  whathitme-client-templates.json 個人用テンプレート（1.3.0+、クライアントのみ）
  hint_template.cfg               /whm dump が書き出す
  pack/                           pack の定義（*.json、サブフォルダー可）
  .cache/                         catalog_cache.json, stats_<uuid>.json, whathitme_dump.csv
```

詳しくは[設定ファイル](/ja/reference/configuration)と [pack フォルダー](/ja/modpack/pack-folder)へ。

## mod を外すとき

`.jar` を削除するだけです。ワールドに保存するのは、サーバーで mod なしのプレイヤーが使った `togglechat` と個人の非表示設定だけです（Forge：プレイヤーの永続データ、Fabric：`<world>/whathitme/players/<uuid>.properties`）。`config/whathitme/` も削除してかまいません。
