# クエスト mod <Badge type="tip" text="1.3.0+" />

[進行度ルール](/ja/modpack/rules)と[死亡トリガー](/ja/modpack/death-triggers)は、クエストの進行度を確認できます。ボスのクエストを終えるまでボスを `???` と表示する、チャプターを終えた後だけヒントを出す、クエストをまだ終えていないプレイヤーにだけ報酬のコマンドを実行する、といった使い方ができます。

## しくみ

- クエスト mod ごとに条件の接頭辞があります。その後にクエスト ID を書き、ルールの `if`、`any`、`unless` のリストに入れます。
- 条件はリフレクションで動きます。クエスト mod が**前提 mod になることはありません**。その mod が入っているときだけ動き始めます。
- 進行度は**サーバー**が、プレイヤー向けの表示を作るたび（死亡のまとめ、リスポーン後の要約、通知、`/whm history` など）に読みます。マルチプレイでも動き、プレイヤーが偽ることはできません。キャッシュしないので、クエストを終えるとすぐ過去の記録にも反映されます。
- mod がない場合や API が合わない場合、条件は**偽**になります。理由はログに 1 回だけ記録され、`/whm reload` でも表示されます。それが原因でゲームが落ちることはありません。

| 接頭辞 | mod | 引数 | Minecraft のバージョン | ページ |
|---|---|---|---|---|
| `ftbquests:` | FTB Quests | クエストかチャプターの 16 進数の ID | 1.12.2、1.15.2、1.16.4 〜 1.21.1、1.21.11、26.1 〜 26.1.2（公開されているもの） | [FTB Quests](/ja/modpack/ftb-quests) |
| `bq:` | Better Questing（GTNH 版、Better Questing Unofficial、4.x も） | クエスト ID（数字。GTNH 版は UUID） | Forge 1.7.10 〜 1.12.2、Forge / NeoForge 1.20.1 | [Better Questing](/ja/modpack/better-questing) |
| `heracles:` | Heracles（現在の名前は「Odyssey Quests」、mod ID は `heracles`） | クエスト ID | 1.20 / 1.20.1、1.21 / 1.21.1 | [Heracles / Odyssey Quests](/ja/modpack/heracles) |
| `stage:` | Game Stages | ステージ名 | Forge 1.11.2 〜 1.20.3、NeoForge 1.20.1 | [Game Stages](/ja/modpack/game-stages) |

バニラの進捗・スコアボードタグ・スコアは[条件](/ja/modpack/conditions)に、`script:` の条件は[スクリプト連携](/ja/modpack/scripts)にあります。

```json
{
  "rules": [
    { "match": "*@twilightforest:lich", "unless": ["ftbquests:4F2A9C1D7B3E6A05"], "name": "???", "hint": "", "hide": ["attacker", "mod"] }
  ]
}
```

## 複数のクエスト mod を組み合わせる

どの接頭辞も同じリストで使えるので、2 つのクエスト mod を入れたパック（たとえば FTB Quests と Game Stages）でも、1 つのルールに混ぜられます。

```json
{
  "rules": [
    {
      "match": "*@cataclysm:ignis",
      "if": ["stage:nether_unlocked"],
      "unless": ["ftbquests:2C7E0B91A4D35F18"],
      "name": "???",
      "hint": "先にクエスト「炎の中へ」を終えよう。"
    },
    {
      "match": "*@cataclysm:ignis",
      "any": ["ftbquests:2C7E0B91A4D35F18", "heracles:ignis_slain"],
      "hint": "耐火のポーションと金のリンゴを持っていこう。"
    }
  ]
}
```

- `if` はすべて、`any` は少なくとも 1 つ、`unless` はどれも満たさないこと。[ルールの選ばれ方](/ja/modpack/rules#how-rules-are-chosen)を参照してください。
- 各 mod の判定は独立しています。入っていない mod の条件は**偽**なので、先頭に `!` を付けると**真**になります。クエスト mod がある版とない版のパックを配るときは注意してください。`unless` に書いた条件は、mod がなければルールを止めません。
- 1 つの pack フォルダーを複数のバージョンのパックで使えます。そのバージョンに入っていない mod の条件は、`/whm reload` に 1 行出るだけです。

## 確認

- `/whm reload` が、入っていないクエスト mod、API の不一致、形の崩れた ID をファイルごとに一覧にします。
- `/whm test <damage_id> [entity] --as <player>` で、そのプレイヤーの実際の進行度でルールを評価します。`--assume <条件>` で条件を満たしたものとして（`--assume !<条件>` で満たしていないものとして）、セーブデータに触れずに試せます。
- [パックエディター](/ja/modpack/pack-editor#condition-picker)は、サーバーが知っているクエストをタイトル付きで一覧にし、入力した ID も確認します。

```
/whm test minecraft:generic cataclysm:ignis --as Steve --assume stage:nether_unlocked --assume !ftbquests:2C7E0B91A4D35F18
```
