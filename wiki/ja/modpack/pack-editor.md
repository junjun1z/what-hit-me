## 予定：`/whm pack`

クエストブックのような画面で、今は pack の JSON とサーバーの設定に書いている**すべて**を編集できるエディターです：名前、ヒント、ルール、死亡メッセージ、テンプレート（テンプレートエディターをタブとして）、死亡トリガー、非表示 ID、`requireClientMod`・`lockedFeatures`・表示スイッチなどのサーバー設定。

| 予定の動作 | 内容 |
|---|---|
| 使える人 | チート有効のシングルプレイ、または OP |
| 開き方 | `/whm pack` と設定画面のボタン |
| 判定はサーバー | クライアントは編集内容を送り、サーバーが JSON を書いてすぐに読み直すので、全員に変更が届く |
| 保存 | 1 項目を確定したとき（Done / 別の項目に移ったとき）。キー入力ごとではない。直前のファイルのバックアップと取り消し |
| カテゴリー | 1 カテゴリー = 1 つの JSON ファイル。作成・名前変更・削除・並べ替え、カテゴリー間での項目の移動。手書きのファイルもカテゴリーとして表示され、不明なキーは残す。カテゴリーの順番も保存され、ファイルをまたいだルールの優先順位がはっきりする |
| フォルダー | サブフォルダーはグループとして表示。テーマ別（`pack/<カテゴリー>.json`）、種類別（`pack/rules/<カテゴリー>.json`）、mod 別など、どの整理方法でも使える |
| メモ | カテゴリーごと・項目ごとのメモ欄を JSON に保存（手書きのコメントは保存時に消えることがある） |
| 補助機能 | ダメージ ID / mob の一覧を検索できるマッチキーの組み立て（ワイルドカードのボタン付き）、サーバーからの一覧（進捗、FTB のクエスト、ステージ、スコアボードの目的とタグ）を使う条件の選択、「このプレイヤーとして / この条件を満たしたとして」のプレビュー（`/whm test --as / --assume` と同じ）、その場でのエラー表示、2 人が同時に編集したときの通知 |

## 予定：個人モード

クライアントの設定画面から開く同じエディター（権限不要）で、**自分の** `renameMap`・`hintMap`・`ignoredDamageIds` を、1 行のカンマ区切りではなく、一覧・検索・マッチキーの組み立て・プレビューを使って編集できます。サーバー専用のタブや条件は表示されません。

コマンド名などの細部は、公開までに変わることがあります。
