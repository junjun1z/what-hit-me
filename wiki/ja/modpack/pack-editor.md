# ゲーム内パックエディター <Badge type="tip" text="1.3.0+" />

`/whm pack` で、[pack フォルダー](/ja/modpack/pack-folder)と `whathitme-common.cfg` に書く**すべて**を、クエストブックのような画面で編集できます：名前、ヒント、[ルール](/ja/modpack/rules)、[死亡メッセージ](/ja/modpack/death-messages)、[テンプレート](/ja/modpack/templates)、[死亡トリガー](/ja/modpack/death-triggers)、非表示 ID、[ロック](/ja/modpack/locked-features)、サーバー設定（表示スイッチ、上限、[`requireClientMod`](/ja/modpack/require-client-mod)）。

| | |
|---|---|
| 使える人 | チート有効のシングルプレイ、または What Hit Me? 入りサーバーの OP（権限レベル 2） |
| 開き方 | `/whm pack`、または設定画面の **パックエディター...** ボタン |
| 判定はサーバー | クライアントは編集内容を送るだけです。サーバーが内容を確認して JSON を書き、すぐに pack を読み直して新しい状態を全員に送るので、`/whm reload` なしで全プレイヤーに反映されます。 |
| 保存 | 1 項目を確定したとき：**完了**、入力欄で Enter、別の項目・タブ・カテゴリーを選んだとき。キー入力ごとには保存しません。 |
| バックアップと取り消し | ファイルを変える前に、直前の内容を `config/whathitme/.backup/<日時>/` にコピーします（サーバー設定の変更では `whathitme-common.cfg` をコピー）。バックアップのフォルダーは新しい 60 個まで残します。**元に戻す**で自分の最後の変更を戻せます。プレイヤーごとに 30 回まで、サーバーが止まるまで覚えています（個人モードは画面を開いている間 30 回）。 |
| 対応バージョン | 画面は対応するすべてのバージョンとローダーにあります：Forge 1.7.10 - 26.3、Fabric 1.14 - 26.3、NeoForge 1.20.1 - 26.3。1.7.10 / 1.8.9 のクライアントは自分の OP レベルを知らないため、`/whm pack` は先にサーバーに確認します（OP でなければ「OP だけ」のメッセージ、設定画面のボタンは自分のリストを開きます）。サーバー側に What Hit Me? 1.3 以降が必要です。古いサーバーでは `/whm pack` がその旨を表示し、設定画面のボタンは自分用のリストを開きます。 |

![ヒントを削除して、元に戻すで復元したところ](/images/ja/pack-editor-undo.gif)

## 画面の構成

![パックエディター：タブ、カテゴリーのツリー、カテゴリーのルール一覧、選んだルールのフォーム](/images/ja/pack-editor.webp)

- 上の**タブ**：リネーム、ヒント、ルール、死亡メッセージ、テンプレート、トリガー、非表示ID、ロック、サーバー設定。タブにはその種類の項目だけが表示されます。
- **カテゴリー**（左）：pack フォルダーの JSON ファイル 1 つが 1 カテゴリー、サブフォルダーはグループです。今のタブの項目がないカテゴリーも灰色で表示されるので、そこに追加できます。`#n` は読み込み順、チェックボックスはカテゴリーのオン／オフ、`✎` はメモあり、赤い `!` は構文エラーのファイル（表示のみ、編集不可）。スクリプトが登録した項目は **スクリプト（読み取り専用）** に出ます。
- **項目**（中央）：選んだカテゴリーの項目と検索欄、**+ 追加**、並べ替えの ↑ / ↓（ルールでは順番が優先順位）。
- **詳細**（右）：選んだ項目の入力欄。その場でエラーと警告を表示し、**完了**・**元に戻す（未保存）**・**削除**・**移動...**（別カテゴリーへ）があります。
- 幅が 400 GUI ピクセル未満の画面（GUI スケールが大きい、古いバージョン）では 3 つを 1 つずつ表示し、**<** で戻ります。

## カテゴリーとフォルダー

カテゴリーツリーの下のボタン：

| ボタン | 動作 |
|---|---|
| `+` | 新しいカテゴリー：選択中のフォルダーの JSON ファイル（既定は `pack/<名前>.json`） |
| `+□` | 新しいフォルダー（ツリーのグループ） |
| `✎` | カテゴリー／フォルダーの名前を変更 |
| `⇨` | 別のフォルダーへ移動 |
| `↑` `↓` | 先に／後で読み込む。後のファイルが前のファイルを上書きし、ルールもこの順に調べるので、ファイルをまたいだ優先順位がはっきりします。 |
| `M` | カテゴリーのメモ |
| `✕` | 削除（バックアップあり、元に戻すで復元）。フォルダーは空のときだけ。 |

テーマごとに 1 ファイルにすべてのセクションを書く方法（新しいカテゴリーの既定）、種類ごとのフォルダー（`pack/rules/<名前>.json`）、mod ごとのフォルダー、どれでも使えます。

![カテゴリーのメモ（M）。メモのあるカテゴリーはツリーに ✎ が付く](/images/ja/pack-editor-memo.webp)

### エディターがファイルに書くキー {#what-the-editor-stores-in-the-files}

| キー | 場所 | 意味 |
|---|---|---|
| `"order": 10` | 最上位 | 読み込み順（小さいほど先）。`order` のないファイルは 0 として扱い、1.3.0 より前と同じくパスのアルファベット順に読み込みます。カテゴリーを動かすとファイルに `order`（10, 20, 30, ...）を書きます。 |
| `"enabled": false` | 最上位 | カテゴリーをオフ：ファイルは残りますが読み込まれません。 |
| `"memo": "..."` | 最上位 | カテゴリーのメモ |
| `"memo": "..."` | ルール／死亡トリガーのオブジェクト内 | その項目のメモ |
| `"entryMemos": {"renameMap": {"<キー>": "..."}}` | 最上位 | マップ／文字列リストのセクション（リネーム、ヒント、死亡メッセージ、テンプレート、非表示 ID、ロック）の項目メモ |

エディターが知らないキーは残します。`order`・`enabled`・カテゴリーのメモはファイルのほかの部分に触れずに書くのでコメントも残りますが、項目を保存するとそのファイルを書き直すため、**そのファイルの手書きのコメントは消えます**。代わりにメモ欄を使ってください。

## 項目

![ルールを追加しているところ：+ 追加、ビルダーでマッチキー、条件の選択で unless の条件、名前 ???、ヒントなし、完了](/images/ja/pack-editor-add-rule.gif)

- **リネーム／ヒント／死亡メッセージ**：マッチキーとテキスト。**選択...** でマッチキービルダーが開きます。
- **ルール**：マッチキー、`if` / `any` / `unless` の条件、名前、ヒント（または「ヒントを出さない」）、隠す項目、強制（自動 = 何かを隠すときオン）、コマンド、プレイヤーごとに 1 回、クールダウン。
- **テンプレート**：出力と行。**テンプレートエディターで編集...** でこの行を[テンプレートエディター](/ja/modpack/template-editor)で開き、そこで **完了** を押すと項目を保存します。
- **トリガー**：マッチキー、コマンド、条件、プレイヤーごとに 1 回、クールダウン。
- **非表示ID／ロック**：1 項目に ID または設定キーを 1 つ（**選択...** でロックできるキーの一覧）。
- どの項目にも**メモ**があります（プレイヤーには表示されません）。

### マッチキービルダー {#match-key-builder}

![マッチキービルダー。mob の一覧を「wither」で絞り込んだところ](/images/ja/pack-editor-keybuilder.webp)

サーバーが知っているダメージ ID とモブ（レジストリ、ダメージ ID スキャナー、記録された死亡）を mod 名付きで検索できる一覧です。行をクリックするとダメージ ID または攻撃者が入り、`*`・`mod:*`・`mob:mod:*` でワイルドカードを入れられます。アイテム（`@item:`）とディメンション（`@dim:`）は別の欄です。[マッチキー](/ja/modpack/match-keys)も参照してください。

### 条件の選択 {#condition-picker}

![条件の選択：左が接頭辞、右がサーバーの進捗](/images/ja/pack-editor-condition.webp)

![FTB Quests を入れたとき：チャプターとクエストがタイトル付きで並ぶ](/images/ja/pack-editor-condition-ftbquests.webp)

条件の接頭辞と、サーバーが一覧にできる値：進捗、スコアボードの目的、オンラインのプレイヤーのタグ、スクリプトの条件、クエスト mod は API が出せるもの（FTB Quests のチャプターとクエストとタイトル、Game Stages の既知のステージ、Better Questing のクエストと名前、GTNH 版も、Heracles のクエストとタイトル）。進捗は 1.12 から、タグは 1.9 からです。灰色の接頭辞はこのサーバーでは使えません（mod がない／バージョン）。**否定（!）** で反転、`score:` は比較と数値を選びます。値は手入力もできます。[条件](/ja/modpack/conditions)も参照してください。

### その場でのチェック

入力欄の下に表示します：不明な条件の接頭辞と `score:` の書式の誤り（保存不可）、mod がない条件や登録されていないスクリプト条件（警告、偽として扱う）、どの既知のダメージ ID / モブにも一致しないマッチキー、不明なテンプレート変数、その項目についての `/whm reload` の警告。

### プレビュー {#preview}

![プレビュー：Steve として、要塞の進捗を満たしたものとして試したところ](/images/ja/pack-editor-preview.webp)

下のバーの **プレビュー** で入力欄の下にテスト欄が出ます。**対象** で進行度を使うオンラインのプレイヤーを選び、その横の欄に満たしたとみなす条件を書きます。**テスト** は、項目のマッチキーについて保存済みの状態で `/whm test <ダメージID> ... --as <プレイヤー> --assume <条件>` と同じ結果を表示します。保存のたびに自動で再実行します。

## サーバー設定

`whathitme-common.cfg` の全キーを設定画面と同じグループで表示します。スイッチはすぐに切り替わり、数値とリストは **適用**（または Enter）で範囲を確認して変更します。OP は pack がプレイヤー向けにロックしたキーも変更できます。

![サーバー設定のタブで requireClientMod を選んだところ](/images/ja/pack-editor-settings.webp)

## 2 人で同時に編集したとき

タイトルに、ほかにエディターを開いている人が表示されます。誰かが保存すると、ほかのエディターに新しい状態と「*名前* が *ファイル* を変更しました」という通知が届きます。そのファイルの項目を編集中なら赤い行で警告し、完了を押すと自分の内容で上書きします（最後の保存が有効）。

## 安全性

すべてサーバーで確認します：メッセージごとの権限（OP／シングルプレイの持ち主）、ファイル名とフォルダー名（英数字、空白、`- _ . ( )`。パスは `config/whathitme/pack/` の中だけ、`..` 不可）、既知のセクションと値の型だけ、サイズの上限（テキスト 8000 文字、マッチキー 600 文字、ファイル 512 KB、セクションごとに 5000 項目、カテゴリー 500 個）。拒否された編集はファイルを変えず、理由をステータス行に表示します。

## 個人モード {#personal-mode}

![個人モード：自分の名前の変更](/images/ja/pack-editor-personal.webp)

権限なしで使える同じエディターです：`/whm pack personal`、または OP でないときの設定画面の **パックエディター...**。`whathitme-client.cfg` の**自分の** `renameMap`・`hintMap`・`ignoredDamageIds` を、1 行のカンマ区切りではなく、同じ一覧・検索・マッチキービルダー・プレビューで編集します。サーバー専用のタブ・条件・メモは表示されず、元に戻すは同じように使えます。OP は左上のタブで **パック** と **個人** を切り替えられます。
