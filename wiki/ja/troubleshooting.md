# トラブルシューティング・FAQ

## 全般

**ほかに何か必要？**
Forge と NeoForge では何もいりません。Fabric では Fabric API だけが必要で、Mod Menu は任意です。

**プレイヤー全員が入れる必要がある？**
いいえ。mod 入りのサーバーなら、入れていないプレイヤーにもチャットの要約とコマンドが英語で届きます。クライアントに入れると、死亡画面のパネル、翻訳、設定画面、クリップボードのボタン、テンプレートが使えるようになります。サーバーは [`requireClientMod`](/ja/modpack/require-client-mod) で必須にもできます。

**mod のないサーバーでも使える？**
使えます。クライアントが自分の体力と周りのエンティティからダメージを推定します。その記録には `[Client Est.]` が付き、詳細は少なめです。この場合、ルールと死亡トリガーは動きません。

**ほかの mod とぶつからない？**
Forge と NeoForge では標準のイベントだけを使い、Mixin もコアモッドも使いません。Fabric では Fabric API のイベントと、イベントがない箇所だけの小さな Mixin を使います。画面を置き換えることはなく、パネルはバニラの死亡画面の上に描くだけです。

**サーバーが重くならない？**
記録するのはプレイヤーだけで、サーバーの tick 処理はなく、通信は死亡時・トーテム / 大ダメージのとき・コマンドのときだけです。履歴はプレイヤーごとの小さなリングバッファです。

**自分の modpack に入れていい？**
どうぞ。MIT ライセンスなので、許可はいりません。

## 何かが表示されない

**パネル / 要約 / 一部の詳細が出ない。**
表示項目は `whathitme-common.cfg` と `whathitme-client.cfg` の**両方**で `true` のときだけ表示されます。サーバーでは、サーバーの common ファイルが使われます。サーバーの管理者に聞くか、`/whm config <key>` で確認してください。

**設定を変えようとすると「locked」と出る。**
pack がそのキーを [`lockedFeatures`](/ja/modpack/locked-features) に入れています。ゲーム内では誰も変更できないので、ファイルを編集してください。

**チャットの要約が多すぎる。消したい。**
`/whm togglechat`、または `enableRespawnChatSummary=false`。modpack 制作者は `whathitme-common.cfg` で全員分をオフにして、ロックもできます。

**あるダメージがまったく出てこない。**
非表示になっているかもしれません（`/whm ignore <id>` で戻せます。`ignoredDamageIds` / `defaultIgnoredDamageIds` も確認）。または `minDamageThreshold`（初期値 0.05）未満のダメージでした。

**「Unknown」や `unknown:` と出るダメージがある。**
mod によっては、どの mod のものか追跡できない形でダメージを作ります。[`renameMap`](/ja/modpack/names-and-tips) で名前を付けてください。

**絵文字がないのはなぜ？**
古い Minecraft のフォントは絵文字を表示できないので、どのバージョンでもゲームのフォントにある記号（☠ ⚠ ❤ ⚡）と文字のラベルを使っています。

## コマンド

**1.1 では `/whm rename` や `/whm reload` が使えたのに、使えなくなった。**
1.2 から、`rename`・`sethint`・`test`・`dump`・`reload` には OP（またはチート有効のシングルプレイ）が必要です。個人の設定は `/whm config` と設定画面で誰でも変更できます。

**`/whm inspect` でサーバーが必要と言われる。**
他のプレイヤーのダメージを知っているのはサーバーだけなので、inspect にはサーバーの mod が必要です。

## pack ファイル

**pack ファイルが効かない。**
1. `/whm reload` を実行して出力を読みます：読み込んだファイル数とエラーのあるファイル数。JSON にエラーがあるファイルは読み飛ばされ、サーバーのログに理由が出ます。
2. ファイル名が `.json` で終わり、`config/whathitme/pack/`（サブフォルダー可）の中にあるか確認します。
3. 項目がコメントアウト（`//`）されたままでないか確認します。
4. `/whm test <damage_id> [entity] [item] [dim]` でキーを確認します。
5. 専用サーバーでは**サーバーの**ファイルを編集します。mod 入りのサーバーに接続している間、クライアントの pack フォルダーは使われません。

**2 つのファイルで同じキーを設定した。どちらが使われる？**
パスのアルファベット順で後のファイルです。[ファイルの読み込み方](/ja/modpack/pack-folder#how-files-are-read)を参照してください。

**特別なヒントより一般的なヒントが使われる。**
`renameMap` / `hintMap` では最も具体的なキー（条件が多い、次にワイルドカードが少ない）が勝ちます。特別なキーが本当に当てはまっているか `/whm test` で確認してください。ルールは**最初に**当てはまったものが使われるので、特別なルールを先に書きます。

## テンプレート <Badge type="tip" text="1.3.0+" />

**テンプレートの行が消える。**
変数がすべて空の行は、意図的に消しています。値がないとき、表示スイッチがオフのとき、ルールで隠されているときに変数は空になります。代わりに何か出したいなら `{変数|代わりの文字}` を使ってください。

**`/whm reload` で「unknown variable」と出る。**
[変数の一覧](/ja/modpack/templates#variables)と綴りを比べてください。エディターでは不明な変数が赤く表示されます。

**個人用テンプレートが使われない。**
pack がその出力をロックしている（`templates` または `templates.<出力名>`）か、その記録に `enforce` / `hide` のルールが当てはまっています。

## 死亡メッセージとルール <Badge type="tip" text="1.3.0+" />

**バニラの死亡メッセージが見えてしまう。**
Forge / NeoForge では、mod **なし**のプレイヤーには常にバニラのメッセージが見えます。[`requireClientMod`](/ja/modpack/require-client-mod) を使ってください。Fabric では全員分が置き換わります。

**ルールがまったく当てはまらない。**
- `/whm reload` の条件の警告を確認します：不明な接頭辞、入っていないクエスト mod、このバージョンで使えない条件（1.12 より前の `advancement:`、1.9 より前の `tag:` など）。
- `/whm test <damage_id> [entity] --as <player>` と `--assume <条件>` で試します。
- 前のルールがすでにその記録に当てはまっているかもしれません（最初に当てはまったものが使われる）。
- ルールにはサーバーの mod が必要です。

**クエストの条件がいつも偽になる。**
クエスト mod が入っていないか、そのバージョンの API が対応していない形です（サーバーのログに 1 回だけ出ます）。[テスト済みのバージョン](/ja/modpack/conditions#quest-mod-matrix)を確認してください。FTB Quests の ID は 16 進数、Better Questing の GTNH 版の ID は UUID です。
